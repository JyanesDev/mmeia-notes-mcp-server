# Notes MCP Server

Notes MCP Server construido siguiendo [MMEIA](https://github.com/JyanesDev/MMEIA-METHODOLOGY-V2) — cuarto Reference Project del catálogo de `05_Reference_Projects` (`04_MCP`).

Demuestra la integración de una API existente con el protocolo MCP: un servidor MCP expone operaciones de la API como Tools, siempre como adaptador — nunca reimplementando lógica propia. Primer Reference Project del catálogo en encadenar cuatro Playbooks (`01_Disenar_Base_Datos` → `02_Crear_API` → `03_Preparar_Despliegue` → `04_Crear_MCP`).

Ver `spec.md`, `requirements.md` y `tasks.md` para la especificación completa antes de cualquier línea de código (FASE 8, Spec antes de Build).
